# Suhas Kolhe — Portfolio

A minimalist, premium personal portfolio website.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions.
Any push to the `main` branch will trigger a deployment to `https://suhaskolhe1.github.io`.
